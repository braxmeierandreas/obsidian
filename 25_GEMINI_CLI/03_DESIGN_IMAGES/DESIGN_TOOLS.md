# Design & Image Generation Tools

## 🎨 Nano Banana (Image Generation)
Powered by Gemini 2.5 Flash Image capabilities.

### Creation
- **`generate_image`**: The versatile all-rounder. Supports styles like photorealistic, watercolor, sketch, etc.
- **`generate_icon`**: Specialized for App Icons, Favicons, and UI elements. Handles rounding, backgrounds, and sizes.
- **`generate_pattern`**: Creates seamless, tiling patterns and textures for backgrounds.
- **`generate_diagram`**: Generates flowcharts, architectural diagrams, and mind maps.
- **`generate_story`**: Creates sequential images (storyboards) with consistent visual style.

### Modification
- **`edit_image`**: Modify specific parts of an image using a text prompt.
- **`restore_image`**: Enhance quality or fix defects in an image.
