# 📅 Das Samstags-Ritual (Vault Maintenance)

> "Konsistenz schlägt Intensität."

Führe dieses Ritual jeden Samstag durch. Dauer: ca. 15-30 Minuten.

## 1. 🛡️ Sicherung & Sync Check
- [ ] **Git Status prüfen**: Öffne das Terminal im Vault.
  ```bash
  git status
  git add .
  git commit -m "Weekly Vault Backup: Samstag [DATUM]"
  ```
  *(Falls du kein Git nutzt, mache ein manuelles Backup auf eine externe Platte/Cloud)*
- [ ] **Sync-Konflikte?**: Suche nach Dateien mit "conflict" oder "konflikt" im Namen und löse sie.

## 2. 📥 Inbox Zero (Aufräumen)
- [ ] **Root-Verzeichnis prüfen**: Liegen lose Dateien (`Unbenannt.md`, `test.md`, `.docx`) im Hauptordner?
    - **Löschen**: Wenn es Müll ist.
    - **Einsortieren**: Wenn es wichtig ist (in `00_INBOX` oder direkt in einen Projektordner).
- [ ] **`00_INBOX` leeren**: Gehe alle Notizen durch, die sich hier angesammelt haben.
    - Ist es eine Aufgabe? -> In den Task-Manager.
    - Ist es Wissen? -> In `30_RESOURCES`.
    - Ist es für ein Projekt? -> In `10_PROJECTS`.

## 3. 🏗️ Struktur-Verbesserung (Nur EINE Sache!)
Nimm dir **einen** alten Ordner oder ein Problem vor. Nicht mehr.
- [ ] Welchen Bereich räume ich heute auf? (z.B. "Den Ordner `06_HOUSEHOLD` in die neue Struktur integrieren").
- [ ] Ordner verschieben & umbenennen.
- [ ] Veraltete Notizen ins Archiv (`40_ARCHIVE`) schieben.

## 4. 🔄 Wochen-Review (Optional aber empfohlen)
- [ ] Habe ich meine Wochenziele erreicht?
- [ ] Was steht nächste Woche an? (Kalender checken)
- [ ] Notiere 3 Dinge, die diese Woche gut liefen.
