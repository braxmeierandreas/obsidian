# Mühle (Nine Men's Morris)

Klassisches Strategiespiel für zwei Spieler.

## Regeln

1. **Setzphase:** Jeder Spieler setzt abwechselnd seine 9 Steine auf die Punkte.
2. **Zugphase:** Steine werden auf angrenzende freie Punkte bewegt.
3. **Mühle:** Wer 3 Steine in einer Reihe hat, darf einen Stein des Gegners entfernen.
4. **Endphase (Fliegen):** Sobald ein Spieler nur noch 3 Steine hat, darf er mit diesen auf jeden beliebigen freien Punkt springen.

## Features

- **Vollbildmodus:** Für maximale Übersicht.
- **Sound:** Synthetische Effekte für Züge und Siege.
- **Menü:** Einfache Navigation.
