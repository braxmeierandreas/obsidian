# Dame - Ultimate Edition

Das klassische Dame-Spiel, vollständig überarbeitet.

## Features

- **Hauptmenü:** Bequeme Navigation und Einstellungen.
- **Spielmodi:**
  - **vs AI:** Tritt gegen den Computer an.
  - **PvP:** Hotseat-Modus für zwei Spieler an einem PC.
- **Schwierigkeitsgrad:** Wähle zwischen Einfach, Mittel, Schwer und Unbesiegbar.
  - *Hinweis:* "Unbesiegbar" rechnet sehr tief (Minimax Algorithmus), das kann kurz dauern!
- **Einstellungen:**
  - Ändere deine Spielerfarbe (Rot, Blau, Grün).
  - Schalte den Ton an/aus.
- **Sound:** Synthetische Soundeffekte für Züge, Schlagen und Sieg (keine externen Dateien nötig).

## Steuerung

- **Maus:** Alles ist klickbar.
- **ESC:** Zurück zum Menü oder Beenden.
