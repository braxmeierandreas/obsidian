# Galgenmännchen (Hangman) Ultimate

Errate das gesuchte Wort, bevor das Männchen am Galgen hängt!

## NEUE Features

- **Multiplayer (Lokal):** Ein Spieler gibt ein geheimes Wort ein, der andere muss es erraten. Perfekt für Duelle!
- **Eigene Wörter hinzufügen:** Du kannst jetzt direkt im Spiel neue Wörter speichern. Diese werden dauerhaft in der `words.txt` hinterlegt.
- **Erweiterte Wortliste:** Über 60 vordefinierte Wörter in drei Kategorien (Einfach, Mittel, Schwer).

## Features

- **Wortlisten:** Über 60 handverlesene deutsche Wörter in drei Schwierigkeitsstufen.
- **Tastatur-Support:** Du kannst Buchstaben einfach auf deiner Tastatur drücken oder mit der Maus klicken.
- **Vollbild:** Umschaltbar für besseren Fokus.
- **Sound:** Akustisches Feedback bei richtigen/falschen Buchstaben und Sieg/Niederlage.

## Regeln

- Du hast maximal 10 Fehlversuche.
- Jedes Mal, wenn du einen falschen Buchstaben wählst, wird ein Teil des Galgens oder des Männchens gezeichnet.
- Errate alle Buchstaben des Wortes, um zu gewinnen.
