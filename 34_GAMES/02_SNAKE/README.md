# 🐍 Snake

Ein klassisches Snake-Spiel.

## 🚀 Starten

Doppelklicke auf **`START_GAME.bat`**.

## 🎮 Steuerung

- **Pfeiltasten:** Bewege die Schlange.
- **Ziel:** Friss die roten Quadrate, um zu wachsen.
- **Verloren:** Wenn du die Wand oder dich selbst berührst.
- **Tasten nach dem Tod:**
  - `C`: Weiterspielen (Neustart)
  - `Q`: Beenden
