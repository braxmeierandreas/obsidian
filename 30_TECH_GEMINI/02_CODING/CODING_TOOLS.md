# Coding & Development Tools

## 🧠 Skills
- **`get-code-context-exa`**: Semantic search across GitHub, StackOverflow, and documentation to find relevant code snippets and patterns.
- **`skill-creator`**: Meta-skill to develop new capabilities for the Gemini CLI itself.

## 🛠️ MCP Tools

### Codebase Analysis
- **`codebase_investigator`**: Deep analysis of project structure, dependencies, and architecture. Useful for onboarding or refactoring.
- **`glob`**: Efficient file finding.
- **`search_file_content`**: Fast regex/text search (ripgrep) within files.

### Development Workflow
- **`run_shell_command`**: Execute any shell command (tests, build scripts, git).
- **`read_file` / `write_file`**: Direct file manipulation.
- **`replace`**: Surgical text replacement for code editing.

### Documentation (Context7)
- **`resolve-library-id`**: Find correct library IDs for documentation.
- **`query-docs`**: Fetch official docs and examples for libraries/frameworks.
